# Token Tracker V5 · 纸与墨 Paper & Ink

V5 redraws the widget family as a paper ledger. It reads the same `/v3` payload as V3 and V4, and every earlier version keeps working alongside it.

## Visual system

- **Paper:** ivory `#FAF9F5` by day and `#1E1D1B` by night, with faint 22 pt ruled lines.
- **Accents:** clay `#D97757` marks *today* only. Sage is used for cache, indigo for latency and amber for projections.
- **Type:**
  - Georgia (regular, bold, italic) for numbers, English and marginal notes.
  - Songti SC (`STSongti-SC-Bold`) for Chinese titles. If the device has no Songti, iOS falls back to its system font.
  - The system sans for small labels, and system monospaced digits for ledger values.
- **Pen marks:**
  - a hand-drawn clay underline under today's number;
  - hatched outlines for past days and a solid bar for today;
  - a dashed box for today's projection and a dashed line marked 均 for the average;
  - ink dots for the 180-day calendar, sized by usage, with today circled;
  - dotted leaders in ledger rows, and three-cell strips between hairlines.
- **Paper crane:** an original 32 × 22 pixel mascot drawn from run-length data in `src/v5/core.js`.
  - *idle* (落笔) when the data is live;
  - *sleep* (打盹) when it comes from cache or the sync is stale;
  - *cheer* (展翅) when the current streak equals the longest one.

## Model icon slots

Every model row and model card has a round slot. At refresh time the widget looks for an image in Scriptable's Documents folder, trying iCloud first and then local storage:

```text
TokenTracker/icons/<family>.png | .jpg
```

`<family>` is one of `claude`, `openai`, `gemini`, `grok`, `deepseek`, `kimi`, `qwen`, `glm`, `minimax`, `doubao`, or the lower-cased family name the backend reports.
- **Shape:** the image is drawn into a square, so use a transparent PNG for a round icon.
- **Default:** a family with no image gets an ink stamp with its initial, in the family's colour.
- **Privacy:** images stay on your device, and the repository ships none.

## Build and previews

- **One source file:** `src/v5/core.js` is the only V5 source. `tools/build_v5.py` writes the seven standalone `scriptable/*V5.js`, and `verify.py` fails if they drift from the core.
- **Previews:** `TT_VERSION=V5 node tools/v4/preview/render.js` renders the real scripts on fictional data through the Scriptable shim, substituting Noto Serif CJK for Georgia and Songti. `TT_VERSION=V5 python3 tools/v4/preview/compose.py` composes `assets/v5/`.

## Data rules (unchanged)

1. Main Token is `prompt_tokens + completion_tokens`.
2. Cache read and cache creation are separate fields, never added to Main Token.
3. Requests are the sum of `request_count`.
4. Latency is the mean of positive `use_time` samples, with no P95/P99.
